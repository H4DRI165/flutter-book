# flutter_book

A Flutter project built to demonstrate mobile development skills and explore modern Flutter architecture patterns.

## About

This project was developed as part of my personal portfolio to showcase my Flutter development skills. It served as a hands-on learning experience for integrating backend services and state management in a real-world app.

## What I Learned & Implemented

- **BLoC (Business Logic Component)** — State management using the BLoC pattern to separate UI from business logic
- **Supabase** — Backend-as-a-service integration for database and storage
- **Authentication** — Implemented user login via:
  - Google Sign-In (OAuth)
  - Supabase Authentication

## Tech Stack

- Flutter
- Dart
- BLoC / flutter_bloc
- Supabase
- Google Sign-In

## Getting Started

1. Clone the repository
2. Run `flutter pub get`
3. Set up your Supabase project and add your credentials to the app
4. Run the app with `flutter run`

## Purpose

This project is part of my developer portfolio and reflects my ability to build structured Flutter applications with real authentication flows and scalable state management.
